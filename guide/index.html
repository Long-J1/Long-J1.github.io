新手上手

这份页面写给第一次拿到这个软件的人。不需要懂任何技术，看完照着做就行。

一、Personal AI 是什么

一个住在这台电脑上的 AI 助手。

它和常见的聊天 AI 有一点不一样：

  • 它记得你。你说过的事、纠正过的事，它会记下来，下次自动用上。你也可以随时查看和删掉它对你的理解。
  • 你的东西不出这台电脑。聊天记录、记忆、照片，全部存在你自己的电脑上，不上传到别人的服务器。
  • 越用越像你。你喜欢的说话方式、习惯、正在忙的事，它会慢慢学。

你可以拿它做什么：

  • 随口跟它说话，让它记住你的事（”我这学期要冲 120 分”）
  • 把拍的照片丢给它，让它帮你整理
  • 问它”刚才我在干什么”，它从记忆里找答案并告诉你依据
  • 懒得整理的事情，让它记

二、第一次使用

整个过程五步，跟着做就行。

第 1 步 · 下载

打开 下载页，点那个绿色的下载按钮。文件大概 110 MB，等它下完。

页面下方有一串 SHA-256 校验码，那是一串”文件的指纹”。你不用管它，它只是用来确认你下到的文件没坏。

第 2 步 · 安装

双击下载好的 PersonalAI-Setup-0.5.4.exe。

  • 会弹出系统的安装确认窗口，点允许（或”继续”）就行
  • 全部保持默认，一路下一步
  • 装完不用创建快捷方式，桌面上没有图标也正常

第 3 步 · 打开

在你自己的程序目录里找到它并双击：

找不到？ 按 Win + R，粘贴上面这行，回车。

第一次打开时它会在后台启动一个”大脑”，等几秒窗口自己就出来了。这是正常的，不是卡死。

第 4 步 · 开启 Beta 体验

第一次打开，首页会有一块绿色的「第一次用？先开 Beta 体验」。

点开启 Beta 体验，把作者给你的体验码粘进去，点解锁体验。

这一步帮你把 AI 模型配好，你不用自己填任何地址、模型名或者密钥。

第 5 步 · 开始聊天

左下角有个输入框（叫 Composer），打字，回车，就开始了。

试试开头的几句：

  • 你好
  • 我最近每天晚上十点后学习效率最高
  • 隔一会儿再问：那我什么时候效率最高？

第二句它会记住，第三句它会用上——这就是它跟普通聊天 AI 不一样的地方。

三、关于 Beta 体验

你需要知道的：

  • 你不需要自己找 Base URL
  • 你不需要自己研究模型名字
  • 你不需要自己装 Ollama
  • 只要有体验码，剩下它替你搞定

关于用量： Beta 期间的网络开销由作者承担，随便用。放心聊。

想关掉？ 首页那块绿色区域里有个「关闭 Beta 体验」。关掉之后：

  • ✅ 你的模型设置会换回你自己原来的那份
  • ✅ 你的记忆、聊天记录一点都不会动

四、高级：自己配置 AI

这一节普通用户不用看。只有当你不用体验码、想接自己的模型时才需要。

方式一：本地模型（Ollama）

需要你电脑上已经装好 Ollama，并且下过至少一个模型。在软件的「模型」面板里：

填什么 填什么内容
Provider 本地 Ollama
Ollama 地址 http://127.0.0.1:11434
模型名 你用 ollama list 看到的那个名字

方式二：云端 API（OpenAI 兼容）

任何 OpenAI 格式的接口都行（智谱、DeepSeek、Kimi、OpenAI 本尊都行）：

填什么 说明
Provider 云端 API（OpenAI-compatible）
API Base URL 服务商给你的地址，通常以 /v1 结尾
模型名 服务商给你的模型名字
API Key 服务商给你的那串密钥

填完点「测试连接」，变成绿的就能用了。

密钥不会被明文显示，存放在你自己电脑上。填的时候如果显示”已保存 xxx”，说明之前存过，留空表示不修改。

五、遇到问题

不用自己分析报错。

最快的方式：截图发给作者。把出错那个界面截下来（按 Win + Shift + S 可以框选截图），发过去就行。

截图时尽量带上：

  1. 整个窗口（别只截一小块）
  2. 底部的状态提示
  3. 如果有报错文字，截进去

其他常见情况：

现象 怎么办
双击没反应 / 窗口没出来 等 10~20 秒再试，第一次启动会慢一些
提示模型不可用 点「Beta 体验」重新解锁一次
界面卡住不动 关掉重开；数据不会丢
想从头再来 「模型」→「数据与备份」里可以清空

七、你的数据在哪

  • 记忆、聊天记录、配置都在这里
  • 和安装目录完全分开：卸载不会删，重装会自动接回来
  • 换电脑：软件里点「导出」拿到一个压缩包，新电脑导入即可

八、卸载

Windows 设置 → 应用 → Personal AI → 卸载。

默认不删记忆。 想彻底清干净，卸载后再手动删上面那个 data 文件夹。

更新日志

记录 Personal AI 的每个正式版本。

v0.2.0 — 2026-09-26

Windows 桌面版发布——第一次可以「双击安装包」使用。

  • 🖥️ 桌面安装包：双击安装、双击启动，内置核心程序自动运行，无需命令行
  • ⚙️ 模型设置：本地模型 / 云端模型（OpenAI 兼容接口）一键热切换、连接测试、密钥脱敏显示
  • 💾 数据管理：导出 / 本地备份 / 恢复，恢复前自动创建安全备份
  • 🧠 Personal Context 读写闭环：对话读理解、沉淀新理解、纠正即刻生效
  • 🔒 卸载不删数据：程序目录与数据目录彻底分离
  • 🛡️ 出错不白屏：端口冲突 / 启动失败 / 崩溃均有明确提示与重试入口

v0.1.0 — 2026-09-26

核心闭环第一版——观察、理解、记忆、回忆。

  • 📷 感知：图片上传 / 摄像头拍照 → 视觉模型理解为结构化事件
  • 🗃️ 记忆：事件写入本机 SQLite，支持时间 / 关键词检索、删除、导出
  • 💬 回忆：「刚才 / 今天 / 上次我在干什么」→ 带依据的回答
  • 🔐 隐私：暂停记录开关、原图不落盘（仅留缩略图）
  • 📋 日志：模型 / 网络 / 数据库错误均有明确日志

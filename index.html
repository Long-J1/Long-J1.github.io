它和普通聊天 AI 有什么不同

🧠 有你的上下文

它记得你是谁、在做什么。回答不是千篇一律的客套，而是带着对你的理解。

🗃️ 有长期记忆

看到的画面变成事件存进记忆库；问「刚才我在干什么」，它从记忆里找答案，并告诉你依据。

✏️ 理解可以修正

它对你的理解白纸黑字列出来：说错了当场改，不想要直接删——解释权在你。

现在就能用（v0.5.4 Beta）

  • 看图理解：上传图片或拍照 → 变成结构化事件存入记忆
  • 带着上下文对话，每轮把新理解沉淀回去
  • 回忆检索：「今天 / 刚才 / 上次」→ 带依据的回答
  • 查看 / 纠正 / 删除它对你的理解，含变更历史
  • 暂停记录（隐私开关）、记忆导出 / 备份 / 恢复
  • 模型随心切：本地模型或云端模型，界面里一键切换
  • Windows 安装包：双击装、双击用，数据与程序分开，卸载不丢记忆

未来方向 （规划中，尚未实现）

语音输入、有分寸的主动介入、从多次事件归纳你的习惯、多设备接力…… 这些是路线图上的方向，不是现在已有的功能——做出来一个，才会写进来一个。

理念：先做灵魂，再做身体。先让它学会观察、理解、记忆、判断， 再长出耳朵、声音和手。

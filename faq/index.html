常见问题

打不开 / 白屏怎么办？

界面会显示红色错误说明和【重试】按钮——按提示点重试，通常即可恢复；不行就重启软件，
再不行重启电脑。仍无法解决时，把日志目录（见使用指南）里的最新日志发给开发者。

提示「端口被占用」？

8000 端口被别的程序占了。错误页会写明具体原因，点【重试】或重启电脑即可。

「测试连接」是红色的？

  • 本地模型：确认 Ollama 正在运行（任务栏右下角看有没有小羊图标），没有就启动它；
  • 云端模型：检查服务地址和 API Key 是否填对（注意 Key 前后别带空格）。

它会把我的数据传上网吗？

不会。记忆和图片只存放在你自己的电脑上。只有你主动配置云端模型时，
发给模型的对话内容才会到达你选的那家服务商——不配云端，就一个字节都不出去。

支持 macOS / Linux 吗？

目前只有 Windows 版。其他平台在未来方向里，还没有实现。

收费吗？

软件本身免费、开源（MIT）。本地模型完全免费；云端模型按你选的服务商价格计费
（不使用云端则无任何费用）。

怎么卸载？记忆会没吗？

设置 → 应用 → Personal AI → 卸载。记忆不会被删除，下次安装自动接着用；
想彻底清掉，手动删除数据目录（见使用指南）即可。

还有问题？

欢迎到 GitHub Issues 反馈（开发者入口）。
